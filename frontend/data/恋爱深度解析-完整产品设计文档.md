### 2.2 模块二：恋爱风格（12题）

**题型**：三选一情境选择题

**测量维度**：六种恋爱风格的主导与辅助倾向

六种风格定义：
- **Eros 激情型**：追求强烈的心动感与身体吸引力，爱得浓烈
- **Storge 友伴型**：从友情发展出爱情，注重陪伴与安心
- **Ludus 游戏型**：享受暧昧和多样性，不愿被约束
- **Mania 占有型**：爱得深沉但焦虑，需要高度确认和控制
- **Pragma 理性型**：注重条件匹配与长远规划，感情讲求实际
- **Agape 奉献型**：无保留地付出，把对方的需要放在自己之前

**计分规则**：每道题三个选项分别对应不同风格加分（见每题标注）

### 2.3 模块三：情感需求优先级（12题）

**题型**：三选一情境选择题

**测量维度**：五大情感需求的得分排序

五大需求定义：
- **安全感**：需要确定感、稳定感，害怕被抛弃或被忽视
- **被看见**：需要被理解、被关注、被认可，渴望情感共鸣
- **自由度**：需要个人空间、独立性，不愿被控制或束缚
- **成长感**：需要在关系中进步、蜕变，渴望共同成长
- **归属感**：需要温暖的陪伴、深层的连接，渴望"在一起"的感觉

**计分规则**：每道题三个选项分别对应不同需求加分（见每题标注）

## 3. 计分逻辑

### 3.1 模块一计分规则（依恋模式）

#### 3.1.1 原始分计算

**焦虑维度原始分（Anxiety_Raw）**：

```
Anxiety_Raw = Q1 + Q4 + Q7 + Q9 + Q11 + Q5×0.5 + Q6×0.5 - (6-Q2)×0.5 - (6-Q12)×0.5
```

> Q1, Q4, Q7, Q9, Q11 为焦虑正向题（各贡献1-5分）
> Q5, Q6 为交叉题（各贡献0.5-2.5分）
> Q2, Q12 为安全题反向计分（各贡献-2.5~+0.5分）

**回避维度原始分（Avoidance_Raw）**：

```
Avoidance_Raw = Q3 + Q8 + Q10 + Q5×0.7 + Q6×0.7 - (6-Q2)×0.5 - (6-Q12)×0.5
```

> Q3, Q8, Q10 为回避正向题（各贡献1-5分）
> Q5, Q6 为交叉题，回避权重0.7（因这两题回避特征更明显）
> Q2, Q12 反向计分

**安全维度原始分（Secure_Raw）**：

```
Secure_Raw = Q2 + Q12
```

#### 3.1.2 标准化得分（0-100）

```
Anxiety_Score = clamp( (Anxiety_Raw - Min_Possible) / (Max_Possible - Min_Possible) × 100, 0, 100 )

Avoidance_Score = clamp( (Avoidance_Raw - Min_Possible) / (Max_Possible - Min_Possible) × 100, 0, 100 )

Secure_Score = clamp( (Secure_Raw - 2) / (10 - 2) × 100, 0, 100 )
```

> 理论范围：
> - Anxiety_Raw: 约3.5 ~ 32.5 → 标准化后 0~100
> - Avoidance_Raw: 约3.9 ~ 33.9 → 标准化后 0~100
> - Secure_Raw: 2~10 → 标准化后 0~100
>
> 具体Min/Max需根据全部题目的权重系数精确计算，开发时以代码为准

#### 3.1.3 依恋类型分类

```
IF Anxiety_Score < 50 AND Avoidance_Score < 50:
    → 安全型（Secure）
ELIF Anxiety_Score >= 50 AND Avoidance_Score < 50:
    → 焦虑型（Anxious-Preoccupied）
ELIF Anxiety_Score < 50 AND Avoidance_Score >= 50:
    → 疏离型（Dismissive-Avoidant）
ELIF Anxiety_Score >= 50 AND Avoidance_Score >= 50:
    → 恐惧型（Fearful-Avoidant）
```

> 注：阈值50为初始设定，上线后可根据实际数据分布微调（如调整为45或55）

#### 1. 安全-激情型 · 炽热守护者

**关键词**：热烈笃定 · 温度方向 · 不灭之火

**核心特质**：
- 在关系中是主动投入的那一方，但不会因此失衡
- 最深的情感需求是"与爱人深度连接"
- 最大天赋是能给予稳定而浓烈的爱
- 最需警惕的是热度过高时忽略伴侣节奏

**依恋维度解读**：
你的安全感来自内在——你相信自己值得被爱，也相信对方的爱。你不需要反复确认，因为你的心自带锚点。焦虑和回避在你这里都处于低位，这意味着你在亲密关系中既不害怕靠近，也不害怕独处。你是少数能在"我们"和"我"之间自然切换的人。

**恋爱风格解读**：
你爱得热烈而投入，心动对你来说是开关而不是调节器。你享受一见钟情的悸动，也享受感情深处的激情。但与焦虑型不同，你的激情不来自匮乏——而来自丰盈。你不是在追光，你本身就是光。

**关系循环模式**：
心动投入 → 深度连接 → 自然升温 → 稳定相守 → 偶尔需要重新点燃 → 小惊喜回归甜蜜 → 循环

**破局关键**：留意伴侣是否跟得上你的节奏，有时候慢下来也是一种深情。

**最佳匹配**：安全-友伴型（暖阳伴侣）——ta的温和节奏为你的热情提供容器，你的火焰让ta的生活不再平淡

**挑战匹配**：疏离-游戏型（随心浪子）——你想要投入，ta想要自由；你越热烈ta越退缩

**成长方向**：学会在激情之外，也欣赏平淡中的深情

#### 2. 安全-友伴型 · 暖阳伴侣

**关键词**：恒温安心 · 陪伴至上 · 细水长流

**核心特质**：
- 在关系中是稳定陪伴的那一方，给人踏实的安全感
- 最深的情感需求是"与爱人安心相处"
- 最大天赋是让关系保持舒适和可持续
- 最需警惕的是过于平淡导致关系缺少惊喜

**依恋维度解读**：
你是天生的关系稳定器。安全感对你来说不是追求，而是常态。你不焦虑、不回避，面对冲突能冷静处理，面对亲密能自然投入。别人在感情里翻江倒海，你却能稳稳地站在岸上，适时伸出手。

**恋爱风格解读**：
你的爱像溪水——不惊天动地，但细水长流。你相信最好的爱情从友情开始，最舒服的相处是"像最好的朋友"。你不追求轰轰烈烈，但要的是"在一起就很安心"。

**关系循环模式**：
自然靠近 → 渐入佳境 → 舒适相处 → 平淡期 → 一次小惊喜/共同经历 → 感情升温 → 循环

**破局关键**：不要把"舒服"当成理所当然，偶尔的仪式感和惊喜是关系的氧气。

**最佳匹配**：安全-激情型（炽热守护者）——ta的热情给你的平淡添彩，你的稳定给ta的火焰提供燃料

**挑战匹配**：焦虑-占有型（执念深情者）——你的淡然会被误解为不在意，ta的占有会让你感到窒息

**成长方向**：学会偶尔"刻意浪漫"，不是所有的甜蜜都要自然发生

#### 3. 安全-游戏型 · 自由精灵

**关键词**：轻盈自在 · 进退自如 · 不被定义

**核心特质**：
- 在关系中是自由洒脱的那一方，投入但不绑定
- 最深的情感需求是"在爱中保持自我"
- 最大天赋是让关系保持轻松愉快的氛围
- 最需警惕的是回避深度导致对方感到不被需要

**依恋维度解读**：
你可能是最"健康"的自由灵魂——你的独立不是因为恐惧，而是因为你真的享受自我。你不怕亲密，但你也不需要它来证明自己的价值。这种从容让你在关系中进退自如。

**恋爱风格解读**：
你享受爱的轻快感——暧昧的心动、约会的雀跃、新鲜感的刺激，这些都是你的燃料。你不排斥深入，但你不会为了"确定"而放弃"可能"。对你来说，爱是一场探索，不是一份合同。

**关系循环模式**：
好奇探索 → 轻松相处 → 自在享受 → 对方渴望更深 → 你犹豫/调整 → 找到平衡或离开 → 循环

**破局关键**：学会区分"我需要空间"和"我在逃避深度"，前者是自由，后者是恐惧。

**最佳匹配**：安全-游戏型（自由精灵）——彼此理解自由的重量，尊重空间的边界，在一起是选择不是必须

**挑战匹配**：焦虑-占有型（执念深情者）——ta需要你的全部，你只想给一部分，需求量级完全错位

**成长方向**：在自由和深度之间找到属于你的交汇点——真正的自由不是随时可以离开，而是选择留下

#### 4. 安全-占有型 · 忠诚守护者

**关键词**：深沉有度 · 忠诚守护 · 占有中有尊重

**核心特质**：
- 在关系中是忠诚守护的那一方，深情但不失控
- 最深的情感需求是"彼此的专属感"
- 最大天赋是在深情中保持理性和尊重
- 最需警惕的是占有欲升温时越界

**依恋维度解读**：
你的安全感足够支撑你爱得深沉。你不是因为害怕失去而占有，而是因为珍惜而守护。这种区别很重要——你的占有欲来自"我真的好喜欢你好想留住你"，而不是"我害怕你不属于我"。

**恋爱风格解读**：
你爱得深沉，像海一样——表面平静，深处翻涌。你希望对方是完全属于你的，但你也有足够的理性去尊重对方的独立性。你的占有欲是"我想要你在我身边"，而不是"你必须在我身边"。

**关系循环模式**：
投入深情 → 专属守护 → 偶尔吃醋 → 表达需求 → 对方理解回应 → 感情加深 → 循环

**破局关键**：当占有欲升温时，问自己："我是在表达爱，还是在施加控制？"——前者拉近关系，后者推开对方。

**最佳匹配**：安全-奉献型（温柔港湾）——ta的付出让你安心，你的守护让ta感到被珍惜

**挑战匹配**：疏离-游戏型（随心浪子）——ta的自由刺痛你的占有，你的约束让ta想要逃跑

**成长方向**：学会把"你只能是我的"转化为"我庆幸你是我的"——占有变成感恩

#### 5. 安全-理性型 · 稳健领航者

**关键词**：章法有度 · 理性经营 · 爱是艺术

**核心特质**：
- 在关系中是理性经营的那一方，有温度也有章法
- 最深的情感需求是"关系可预期、可发展"
- 最大天赋是把爱经营成可持续的模式
- 最需警惕的是过度理性让对方觉得"不够爱"

**依恋维度解读**：
你的安全感建立在"一切在掌控中"的基础上——你知道关系的走向，你理解伴侣的需求，你能预见并解决问题。这种能力让你在感情中很少失控，但偶尔也会让人觉得你太"冷静"了。

**恋爱风格解读**：
你相信好的爱情需要经营，就像经营一份事业。三观匹配比心动重要，生活习惯比甜言蜜语重要，未来规划比浪漫仪式重要。你并不是不懂浪漫——你只是更相信"相濡以沫"比"海誓山盟"靠得住。

**关系循环模式**：
条件评估 → 理性进入 → 稳步经营 → 感情升温 → 规划下一步 → 共同成长 → 循环

**破局关键**：允许自己偶尔"不讲道理"——爱不需要每次都最优解，有时候"就是想见你"已经是最充分的理由。

**最佳匹配**：安全-友伴型（暖阳伴侣）——你们都信奉细水长流，一个提供方向一个提供温暖

**挑战匹配**：恐惧-激情型（摇摆焰火）——ta的情绪波动超出你的预测模型，你的冷静让ta觉得不被在乎

**成长方向**：学会在规划之外留一点"意外的空间"——最好的爱情故事，往往不是按剧本走的

#### 6. 安全-奉献型 · 温柔港湾

**关键词**：有边界的温柔 · 付出不耗竭 · 爱人也爱己

**核心特质**：
- 在关系中是温暖给予的那一方，但守住自我边界
- 最深的情感需求是"我能让爱人幸福"
- 最大天赋是让对方感到被无条件接纳
- 最需警惕的是在付出中忘记自己也需要被照顾

**依恋维度解读**：
你的安全感让你能安心地给予——你不需要对方立刻回报，因为你知道爱不是交易。但你也清楚自己的边界在哪里，不会因为爱一个人就把自己燃尽。这是你最大的优势：温柔但有力量。

**恋爱风格解读**：
你天生懂得如何爱人——你会记住对方随口说的小事，会在对方低谷时第一个出现，会用自己的方式默默填满对方的需求。但与焦虑型奉献者不同，你的付出是有选择的、可持续的。

**关系循环模式**：
用心付出 → 对方感动回应 → 感情加深 → 偶尔感到疲惫 → 表达需求 → 对方回馈 → 恢复平衡 → 循环

**破局关键**：定期检查自己的"能量条"——爱别人之前，先确保自己不是在空转。

**最佳匹配**：安全-占有型（忠诚守护者）——你给的温柔ta珍惜，ta的守护让你安心

**挑战匹配**：疏离-游戏型（随心浪子）——你给的温暖ta不一定需要，ta的自由让你觉得付出没有回应

**成长方向**：学会"直接要"——被爱不需要用付出来换，有时候一句"我需要你"就够了

#### 7. 焦虑-激情型 · 追光者

**关键词**：全力以赴 · 渴望回应 · 容易内耗

**核心特质**：
- 在关系中是全力追逐的那一方，爱得毫无保留
- 最深的情感需求是"被热烈地回应"
- 最大天赋是能创造极致的浪漫和心动体验
- 最需警惕的是过度付出后因得不到等量回应而崩溃

**依恋维度解读**：
你不是不信任爱，你是不确定自己值得被爱。你的焦虑不是因为脆弱——恰恰相反，你太在乎了。每一个未回复的消息、每一次冷淡的语气，在你心里都会被放大十倍。你需要反复确认，不是因为贪心，而是因为不安。

**恋爱风格解读**：
你爱得像一场烟火——明亮、炽热、不顾一切。心动对你来说是氧气，激情是你存在的证明。但烟火的宿命是短暂，你在每段感情的开头都飞蛾扑火，然后在热情退去后陷入深深的自我怀疑。

**关系循环模式**：
心动投入 → 全力付出 → 微小忽视引发焦虑 → 试探/索取确认 → 对方压力增大退缩 → 焦虑升级 → 爆发或压抑 → 和好后短暂安心 → 循环

**破局关键**：你的循环卡在"微小忽视→焦虑"这一步。下一次当你因为一个小细节不安时，先暂停5秒问自己："这是事实，还是我在编故事？"

**最佳匹配**：安全-友伴型（暖阳伴侣）——ta的稳定能接住你的波动，你的热情让ta的生活不再平淡

**挑战匹配**：疏离-理性型（独立远航者）——你追ta逃，你越靠近ta越退，核心是安全感语言不同

**成长方向**：学会在爱里给自己留一盏灯——不是所有的付出都需要被看见，但你的感受需要被自己看见

#### 8. 焦虑-友伴型 · 渴望陪伴者

**关键词**：害怕独处 · 需要确认 · 温柔依赖

**核心特质**：
- 在关系中是依赖陪伴的那一方，需要"在一起"的感觉
- 最深的情感需求是"不孤单、不被丢下"
- 最大天赋是能创造温暖亲密的日常
- 最需警惕的是过度依赖导致失去自我

**依恋维度解读**：
你的焦虑不来自爱的浓度，而来自"距离"——你害怕的不是对方不爱你，而是对方不在身边。独处时你的焦虑会被放大，陪伴是你的止痛药。你需要的不是轰轰烈烈，而是"一直在"。

**恋爱风格解读**：
你要的爱情很简单——一起吃饭、一起散步、一起说废话。你不在意浪漫的仪式，你在意的是日常里的陪伴。但问题在于，当对方需要空间时，你会觉得被抛弃。

**关系循环模式**：
安心陪伴 → 对方需要独处 → 你感到不安 → 紧贴/索取关注 → 对方感到压力 → 短暂冷淡 → 你更不安 → 反复确认 → 和好 → 循环

**破局关键**：学会在"ta不在身边"的时候也能找到安心——独处不是被抛弃，是你们都在充电。

**最佳匹配**：安全-奉献型（温柔港湾）——ta愿意持续给予陪伴，你的依赖在ta看来是信任

**挑战匹配**：疏离-游戏型（随心浪子）——ta的世界很大，你的世界只有ta，需求量级严重不匹配

**成长方向**：建立"一个人的安心"——你的幸福不该完全绑定在另一个人身上，学会享受独处

#### 9. 焦虑-游戏型 · 试探者

**关键词**：渴望又恐惧 · 暧昧高手 · 内心拉扯

**核心特质**：
- 在关系中是若即若离的那一方，主动靠近又害怕受伤
- 最深的情感需求是"被喜欢但不用太深入"
- 最大天赋是能制造令人心动的心动氛围
- 最需警惕的是反复试探最终把真心人推走

**依恋维度解读**：
你是焦虑型里最矛盾的存在——你渴望被爱，但又害怕太深入会受伤。所以你的策略是：保持暧昧、反复试探。你需要确认对方是认真的，但确认的过程本身就是你在逃避。

**恋爱风格解读**：
你享受暧昧的刺激——那种"ta喜欢我吗"的不确定性反而让你安心，因为还没确定就不会失去。但一旦关系要进入下一阶段，你的焦虑就会升级。

**关系循环模式**：
暧昧心动 → 你主动靠近 → 关系要深入 → 你开始恐惧 → 后退/冷淡 → 对方失望/离开 → 你后悔 → 重新靠近 → 循环

**破局关键**：你的循环卡在"关系要深入→恐惧"这一步。问问自己："我在害怕什么？如果真的被伤害了，我还能站起来吗？"——答案通常是：能。

**最佳匹配**：安全-激情型（炽热守护者）——ta的热烈和笃定能融化你的犹豫，ta不会因为你的退缩而离开

**挑战匹配**：疏离-理性型（独立远航者）——两个都在逃的人在一起，没有人来拉住彼此

**成长方向**：学会"信任心动"——不确定才是最确定的信号，勇敢往前走一步不会失去什么

#### 10. 焦虑-占有型 · 执念深情者

**关键词**：深海暗涌 · 爱到窒息 · 极致占有

**核心特质**：
- 在关系中是全力占有的一方，爱得深沉而浓烈
- 最深的情感需求是"你是我的，只属于我"
- 最大天赋是能给予极致的深情和专注
- 最需警惕的是控制欲升级到伤害彼此的程度

**依恋维度解读**：
你的焦虑和占有欲是一对双生子——你越在乎越焦虑，越焦虑越想控制。你不是在控制对方，你是在试图控制自己的恐惧。但控制从来不能消除恐惧，只会让恐惧在暗处长出更深的根。

**恋爱风格解读**：
你爱得像深海——表面看是深情的蓝，底下是翻涌的暗流。你的占有欲不是恶意，而是爱的极致表达。但对方感受到的可能不是"你有多爱我"，而是"被你绑住了"。

**关系循环模式**：
深情投入 → 占有欲升温 → 过度关注/控制 → 对方感到窒息 → 反抗/疏远 → 你焦虑升级 → 更紧的控制 → 对方逃离 → 崩溃 → 请求和好 → 循环

**破局关键**：你的循环卡在"占有欲→控制"这一步。下一次想查手机/质问/限制时，先做一件事：把注意力转向自己——"我此刻需要的是什么？除了控制对方，还有别的方式满足这个需要吗？"

**最佳匹配**：安全-奉献型（温柔港湾）——ta的无条件接纳让你的占有欲有安放之处，你不需要控制一个甘愿留下的人

**挑战匹配**：疏离-游戏型（随心浪子）——你越抓ta越跑，你们之间永远在玩猫鼠游戏

**成长方向**：学会"松手也是爱"——真正的拥有不是抓住，而是对方心甘情愿地留下

#### 11. 焦虑-理性型 · 反复权衡者

**关键词**：分析瘫痪 · 想信又怕 · 感性理性拉锯

**核心特质**：
- 在关系中是反复分析的那一方，想爱又怕受伤
- 最深的情感需求是"确定性——确保这段关系值得"
- 最大天赋是能理性分析关系问题，找到最优解
- 最需警惕的是过度分析导致错过真心

**依恋维度解读**：
你的焦虑不表现为情绪崩溃，而是脑内的疯狂计算——ta说这句话是什么意思？ta不回消息是因为忙还是不在意？我们的未来可行吗？你用理性试图控制焦虑，但越分析越焦虑，越焦虑越分析。

**恋爱风格解读**：
你选择伴侣像在做决策分析——条件匹配度、长期可行性、风险收益比。这不是冷血，而是你的防御机制：只要我能证明这段关系是"对的"，我就可以放心地爱。但问题是，感情从来不是100%确定的。

**关系循环模式**：
心动 → 开始分析 → 发现疑点 → 权衡利弊 → 越分析越焦虑 → 想放弃又不甘心 → 反复横跳 → 最终做决定（通常太晚）→ 循环

**破局关键**：你的循环卡在"分析→焦虑→更多分析"这个死循环。设定一个"决策期限"——给自己3天时间分析，到期就凭直觉做决定。

**最佳匹配**：安全-激情型（炽热守护者）——ta的果断和热烈能打破你的分析循环，ta让你相信"有时候心动就够了"

**挑战匹配**：恐惧-理性型（进退两难者）——两个都在分析的人在一起，关系变成了永无止境的谈判

**成长方向**：学会"先跳再想"——不是所有决定都需要最优解，有些路只有走了才知道方向对不对

#### 12. 焦虑-奉献型 · 过度付出者

**关键词**：燃尽自己 · 爱是给予 · 隐痛付出

**核心特质**：
- 在关系中是全力付出的那一方，把自己的需求放在最后
- 最深的情感需求是"我的付出被看见和珍惜"
- 最大天赋是无条件地给予温暖和支持
- 最需警惕的是耗竭自己后积累怨气，最终爆发

**依恋维度解读**：
你的焦虑通过付出来表达——你不敢直接要，所以你选择先给。"我对你这么好，你应该不会离开我吧"——这是你内心深处没有说出口的公式。但这个公式不总是成立，有时候你的好反而让对方觉得有压力。

**恋爱风格解读**：
你爱的语言是"为你做"——记住你的喜好、照顾你的情绪、为你改变自己的计划。你以为爱就是不断给予，但忘了爱也包含"允许被爱"。

**关系循环模式**：
发现对方需要 → 全力付出 → 期待回应 → 回应不够 → 继续加大付出 → 疲惫但不停止 → 积累怨气 → 爆发"我为你做了这么多" → 对方愧疚/退缩 → 冷却 → 你又心疼重新付出 → 循环

**破局关键**：你的循环卡在"付出→期待→更多付出"这一步。在每次想为对方做什么之前，先问自己："我做这件事是因为我想做，还是因为我希望ta因此更爱我？"

**最佳匹配**：安全-占有型（忠诚守护者）——ta的深情回应让你的付出有回响，ta的守护让你安心

**挑战匹配**：疏离-游戏型（随心浪子）——你给的不是ta想要的，ta要的你给不了——自由和深情在这里碰壁

**成长方向**：学会"空着双手去爱"——你不一定非要"有用"才值得被爱，你的存在本身已经是礼物

#### 13. 疏离-激情型 · 冷焰旅人

**关键词**：远处燃烧 · 看得见走不近 · 冷与热的边界

**核心特质**：
- 在关系中是远观投入的那一方，心动但保持距离

**恋爱风格解读**：
你容易被强烈的吸引力打动——一见钟情的心动、灵魂共鸣的瞬间，这些你都会感受到。但当关系要从心动走向亲密时，你的本能反应是后退。你享受"喜欢"的感觉，但不适应"在一起"的日常。

**关系循环模式**：
远远心动 → 靠近一些 → 感觉到亲密的压力 → 后退 → 对方失落 → 你也失落但不愿承认 → 在远处继续心动 → 再次试探靠近 → 循环

**破局关键**：你的循环卡在"靠近→压力→后退"这一步。问自己："我在害怕什么？亲密真的会吞没我吗？"——试试让一个人走进来，你会发现你还你。

**最佳匹配**：安全-友伴型（暖阳伴侣）——ta的温和不给你压迫感，ta用最温柔的方式让你习惯"靠近"

**挑战匹配**：焦虑-占有型（执念深情者）——ta的追逐让你想逃，你的退缩让ta更焦虑，恶性循环

**成长方向**：学会"走近了，你还你"——亲密不是融化，是两团火焰并肩燃烧

#### 14. 疏离-友伴型 · 安静同行者

**关键词**：并排走不牵手 · 安静陪伴 · 独立的温暖

**核心特质**：

**依恋维度解读**：
你的回避不冷血——你只是需要自己的空间。你能享受陪伴，但更享受"你在旁边，我在做自己的事"这种模式。你给的温暖是安静的、不张扬的，但确实是温暖的。

**恋爱风格解读**：

**关系循环模式**：
自在相处 → 关系稳定 → 对方渴望更多亲密 → 你本能后退 → 对方失落 → 你解释但不愿改变 → 距离拉大 → 你感到孤独但不愿主动 → 循环

**破局关键**：你的循环卡在"对方渴望更多→后退"这一步。试着理解：对方的"更多"不是控制，是爱的方式不同。偶尔主动靠近一步，不会失去自己。

**最佳匹配**：安全-理性型（稳健领航者）——你们都信奉"有边界的亲密"，尊重彼此空间又有深度连接

**挑战匹配**：焦虑-友伴型（渴望陪伴者）——ta需要你在身边，你需要自己的空间，需求完全相反

**成长方向**：学会"主动靠近也是自由"——偶尔的亲密不是妥协，是你选择给出的温柔

#### 15. 疏离-游戏型 · 随心浪子

**关键词**：自由至上 · 来去如风 · 不愿被定义

**核心特质**：
- 在关系中是自由飘荡的那一方，享受当下但不承诺
- 最深的情感需求是"完全的自我空间和选择权"
- 最大天赋是让关系轻松有趣没有压力
- 最需警惕的是用"自由"逃避所有深度连接

**依恋维度解读**：

### B. 阈值调优建议

上线初期建议：
1. 收集前500份测试数据
2. 分析各维度得分分布
3. 根据实际分布调整依恋分类阈值（当前50分位）
4. 如分布偏斜严重，可考虑四分位分类法

### C. 报告生成方式建议

**推荐方案：预设模板 + 变量填充**

理由：
- 24种人格的解读文本提前编写，质量可控
- 避免AI实时生成的不稳定性和延迟
- 情感需求排序部分用条形图动态渲染
- 报告生成速度快（<1秒），用户体验好
